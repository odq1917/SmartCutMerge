# SmartCutMerge

방송 녹화본에서 **일부 구간을 잘라내고 여러 파일(1부·2부 등)을 하나로 합치는** Windows 도구입니다.
편집 프로그램처럼 전체를 다시 렌더링하지 않고, **자르는 지점 앞뒤 몇 초만 재인코딩**하고 나머지는 원본 영상을 그대로 복사합니다.

- 2~3시간짜리 영상도 디스크 복사 속도 수준으로 처리 (재인코딩은 경계 몇 초뿐)
- 영상 화질 손실 없음 (복사 구간은 원본과 비트 단위로 동일), 출력 용량 ≈ 원본 합계 − 잘라낸 분량
- 잘라낸 구간은 결과물에 **완전히 남지 않습니다** (복사 구간은 키프레임 경계에서 끊고, 경계 부분은 새로 인코딩). 단, 컷 지점은 ±1프레임 오차가 있을 수 있으니 민감한 내용은 앞뒤로 1~2초 여유를 두고 지우세요

## 사용법

1. [Releases](../../releases)에서 `SmartCutMerge.exe`를 받아 실행합니다. ffmpeg가 내장되어 있어 따로 설치할 필요가 없습니다.
   (첫 실행 때 압축을 푸느라 몇 초 걸립니다.)
2. 실행 후 파일을 **재생 순서대로** 추가합니다. (1부 → 2부)
3. 잘라낼 파일을 선택하면 미리보기가 뜹니다. 슬라이더/±버튼(프레임 단위 포함)으로 장면을 찾아 **시작으로 / 끝으로** 지정하고 구간 추가.
   `▶ 재생`(스페이스바)으로 0.5x~8x 배속 재생도 됩니다. 타임라인을 끌어 양쪽 끝 밖으로 가면 맨 처음/맨 끝에 붙습니다.
   시간을 직접 입력해도 됩니다. 미리보기는 화면만 보여주며 소리는 나오지 않습니다.
   시간 형식: `1:02:10.5`, `62:10`, `3730`. 끝을 비우면 영상 끝까지 잘라냅니다.
4. 저장 경로 지정 → 시작.

### 명령줄

```
SmartCutMerge.exe 출력.mp4 "1부.mp4@1:02:10-1:02:40,1:30:00-1:31:00" "2부.mp4@0-0:20"
```
`@` 뒤는 **삭제할** 구간입니다.

## 동작 방식

1. 키프레임 위치를 분석해, 남길 구간을 `[앞 가장자리 재인코딩] + [키프레임~키프레임 무손실 복사] + [뒤 가장자리 재인코딩]`으로 나눔
2. 조각들을 MPEG-TS로 만든 뒤 하나로 이어 붙여 MP4/MKV로 저장

## 제한 사항

- H.264 / H.265 영상만 지원. 오디오는 항상 AAC로 다시 인코딩합니다 (용량 영향 거의 없음, 싱크 정확도를 위함).
- 1부·2부의 해상도/프레임레이트/코덱 등이 다르면 자동으로 전체 재인코딩으로 전환됩니다 (느림). 같은 OBS 설정이면 문제 없습니다.
- H.265를 소프트웨어 인코더의 open-GOP 설정으로 녹화한 파일은 컷 경계에서 1~2프레임이 깨질 수 있습니다 (NVENC/QSV/AMF 등 일반 OBS 녹화는 해당 없음).
- 오디오 트랙은 모두 유지하지만 자막/데이터 스트림은 버립니다.
- 결과물 크기만큼의 여유 디스크 공간만 있으면 됩니다 (영상은 임시 파일 없이 바로 결과물로 씁니다).
- 입력 파일은 수정하지 않습니다.
